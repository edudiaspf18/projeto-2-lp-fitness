# WinnerFit — Landing Page

Landing page moderna para o app fitness **WinnerFit**, desenvolvida com HTML e CSS puro. Layout clean, responsivo e focado em conversão para download do aplicativo.

## Demo

Abra o arquivo `index.html` no navegador ou acesse o repositório publicado no GitHub Pages (se configurado).

## Tecnologias

- HTML5 semântico
- CSS3 (Flexbox, Grid, custom properties, media queries)
- Google Fonts — [Inter](https://fonts.google.com/specimen/Inter)
- Sem JavaScript, frameworks ou bibliotecas CSS

## Estrutura do projeto

```
├── index.html      # Página principal
├── style.css       # Estilos e layout responsivo
├── imgs/           # Prints do aplicativo
└── README.md
```

## Seções da página

- **Header** — logo WF e botão de download
- **Hero** — slogan, print principal e destaques (Saúde, Exercício, Amigos)
- **Funcionalidades** — calorias, exercícios e compartilhamento com amigos
- **CTA** — chamada para download gratuito
- **Rodapé** — direitos autorais e links institucionais

## Responsividade

A página segue abordagem **mobile-first** e se adapta a:

- Celulares
- Tablets
- Notebooks
- Desktops e telas grandes

## Como executar localmente

Clone o repositório e abra `index.html` no navegador:

```bash
git clone https://github.com/edudiaspf18/projeto-2-lp-fitness.git
cd projeto-2-lp-fitness
open index.html
```
